# Asset Credits

Squelch: Dead Air FM uses original project assets, locally stored audio, and open-source fonts. No third-party artwork or audio is hotlinked.

## Original Artwork and Assets

The following assets were created specifically for this project using procedural generation or hand-written SVG.

| Assets | Description |
|---|---|
| `public/assets/characters/squelch-*.svg` | Original pixel-art character sprites representing Squelch's different moods |
| `public/assets/backgrounds/lowtide-hollow.svg` | Pixel-art night scene depicting Lowtide Hollow |
| `public/assets/backgrounds/scene-*.svg` | Pixel-art scenes used throughout the experience |
| `public/assets/textures/scanlines.svg` | CRT scanline texture |
| `public/assets/textures/noise.svg` | Visual noise texture |
| `public/assets/textures/grille.svg` | Speaker grille texture |
| `public/favicon.svg` | Custom pixel-art favicon |

## Fonts

Fonts are bundled locally through [`@fontsource`](https://github.com/fontsource/fontsource). Each font is distributed under the SIL Open Font License 1.1. License texts are included in `public/assets/fonts/`.

| Font | Designer / Foundry | Usage |
|---|---|---|
| Pixelify Sans | Stefie Justprince | Headings |
| Silkscreen | Jason Kottke | System labels and buttons |
| VT323 | Peter Hull | Terminal and LED readouts |
| Space Mono | Colophon Foundry | Body text |

Only the Latin subsets required by the project are included.
